# Java Calculator

A simple calculator application built with Java to perform basic arithmetic operations. This project demonstrates fundamental Java programming concepts and serves as a beginner-friendly console application.

## Features

- Perform basic arithmetic operations: addition, subtraction, multiplication, and division.
- Accept user input.
- Display calculation results.
- Simple and easy-to-use interface.

## Technologies Used

- **Java** — Programming language
- **JDK** — Java Development Kit
- **Git & GitHub** — Version control and source code hosting

## Getting Started

### Prerequisites

Install the Java Development Kit (JDK) on your computer.

Verify your installation:

```bash
java -version
javac -version
```

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/favaz-am/Java-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Java-Calculator
   ```

3. Compile the Java source file:

   ```bash
   javac calculator.java
   ```

4. Run the application:

   ```bash
   java calculator
   ```
